========================================
【怎么把网址发给别人】
========================================

对方什么都不需要装——只要在手机/电脑浏览器里打开你发
的网址就能播放。你需要做的只是"把文件夹上传一次"：

方法一（最简单，不用注册账号）：
1. 打开 https://app.netlify.com/drop
2. 把整个 birthday_gift 文件夹用鼠标拖到网页中间，
   松开鼠标，自动上传并生成一个网址
3. 把网址发给对方，点开即可。
   （注意：不登录账号的匿名网址可能过一段时间失效，
   适合先发给对方看；想长期保留请看方法二）

方法二（长期稳定，国内访问快，推荐）：
1. 注册一个 Gitee（码云）账号，免费：https://gitee.com
2. 新建一个仓库 → 把整个文件夹上传 → 打开"服务 → Gitee
   Pages" → 部署，生成网址（形如 xxx.gitee.io/仓库名）
3. 这个网址长期有效、国内打开快。

方法三：
GitHub 账号 + GitHub Pages，步骤类似方法二，
但国内访问可能稍慢。

【分享前自检】
1. 自己先点开网址完整看一遍：照片墙、蛋糕、音乐都有，
   说明成功了。
2. 音乐需要先点击一下画面才开始播放（浏览器规定），
   动画第一屏本来就要点击，所以不受影响。

========================================
【以后想修改怎么办】（完全不影响）
========================================
不用 Processing 也能改！sketch_260831c.js 就是普通文本，
用任意编辑器打开：
- Windows：记事本（右键 → 打开方式 → 记事本）就能改
- 想更顺手：下载免费的 VS Code 或 Notepad++

改完保存 → 覆盖进文件夹 → 重新上传到托管平台 → 刷新网页，
新效果就生效。网页结构（index.html）永远不用动。

常用修改位置都在文件开头的 CFG 配置里：
- 照片说明文字：CFG.photoWall.photoTexts（加 \n 可换行）
- 蛋糕大小：CFG.cake.size（0.33 = 屏幕高度的三分之一）
- 蛋糕各素材大小：CFG.cake.imageScale
- 音乐音量：CFG.music.volume（0~1）
- 音效音量：CFG.sfx 里的 matchVolume / rustleVolume / birthdayVolume
- 生日快乐歌速度/遍数：CFG.sfx.birthdayBeat / birthdayPasses
- 想换背景音乐：把新歌转成 mp3，命名 music.mp3 放进 data/ 覆盖
